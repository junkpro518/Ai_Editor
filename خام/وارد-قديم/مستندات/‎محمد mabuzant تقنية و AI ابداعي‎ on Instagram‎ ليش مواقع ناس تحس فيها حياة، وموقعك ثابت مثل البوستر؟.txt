Title: ‎محمد mabuzant | تقنية و AI ابداعي‎ on Instagram‎: "ليش مواقع ناس تحس فيها حياة، وموقعك ثابت مثل البوستر؟

تقدر تعلّم Claude Code مهارات جديدة بأمر واحد، وتظل معاه كل جلسة بدل ما تعيد الشرح كل مرة. هذي الخمس اللي تخلي اللي تبنيه يتحرك، وكلها مجانية ومفتوحة المصدر:

1. Three.js: مشاهد 3D، كاميرا، إضاءة
git clone https://github.com/CloudAI-X/threejs-skills
(وانسخ مجلد .claude/skills لمشروعك)

2. GSAP، الرسمية من GreenSock: Timelines و ScrollTrigger
/plugin marketplace add greensock/gsap-skills

3. Design DNA: يطلّع تصميم أي موقع كـ tokens
npx skills add zanwei/design-dna -a claude-code -g -y

4. Motion Design من فريق LottieFiles: التوقيت والـ easing وترتيب الحركة
npx skills add LottieFiles/motion-design-skill

5. Genjutsu: cast و paint و bunshin
/plugin marketplace add AThevon/genjutsu
/plugin install genjutsu

مب عارف من وين تبدأ؟ ابدأ بـ Design DNA.
احفظ البوست لجلسة البناء الياية، وأرسله لصديقك المصمم.
