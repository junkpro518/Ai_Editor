🇨🇳 مطور صيني نشر أداة مجانية اسمها: «طابعة الفلوس» 💰

ووصلت إلى 110 آلاف نجمة على GitHub.

تكتب موضوع، أو حتى جملة وحدة فقط… والباقي عليها.

ترجع لك فيديو عمودي HD جاهز للنشر، بصوت وتعليقات وموسيقى.

وش تسوي لحالها؟

→ تكتب السكربت بالذكاء الاصطناعي
→ تستخرج الكلمات المفتاحية وتبحث عن المقاطع المناسبة
→ تحمل المقاطع من Pexels وPixabay وCoverr
→ تضيف تعليق صوتي TTS
→ تنشئ ترجمة متزامنة وتتحكم بالخط واللون والمكان
→ تضيف موسيقى خلفية
→ وتصدر الفيديو بمقاس 9:16 أو 16:9

والأقوى؟

تنشر الفيديو تلقائيًا على TikTok وInstagram وYouTube Shorts.

تضبط المفاتيح مرة وحدة، وبعدها الفيديو يننشر تلقائيًا بدون ما تسوي شيء.

وتقدر بعد تنتج عدة فيديوهات دفعة وحدة، مثلًا تطلب 10 فيديوهات عن نفس الموضوع وتختار الأفضل.

وما تحتاج GPU.

حتى الصوت الافتراضي مجاني وما يحتاج API Key.

وتقدر تستخدمها بأربع طرق:

→ واجهة ويب
→ API
→ سطر الأوامر
→ تعطي الـSkill لوكيل الذكاء الاصطناعي، وهو يثبتها ويضبطها لك

Windows: فك الضغط واضغط مرتين.
Mac وLinux: Docker أو uv.
