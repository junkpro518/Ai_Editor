🖌️ 卧槽，Upscayl 能把糊掉的老照片放大到重新看清细节，而且全程在自己电脑上跑，图片一张都不用传出去。

GitHub 上狂揽 4.9 万 star，完全免费开源，Linux、macOS、Windows 三个平台都有现成安装包。

翻出十年前手机拍的照片想洗出来，一放大全是马赛克。以前的选择无非两个：找个在线放大网站，排队、限张数，还得把自己的相册交给别人；或者掏钱买商业软件。Upscayl 装在本地，用 Real-ESRGAN 加 Vulkan 直接调你的显卡跑，还内置了好几套不同风格的模型，人像、插画、老照片各挑各的。

有两件事得说在前面：它需要一块支持 Vulkan 的显卡，多数核显和纯 CPU 的机器跑不动；它也只擅长救分辨率低、有像素块的图，拍糊了、对焦跑了的照片它帮不上忙。

照片放大这件事，终于不用先把自己的相册交出去了。
