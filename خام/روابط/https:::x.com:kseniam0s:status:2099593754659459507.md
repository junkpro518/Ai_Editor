Top 8 @github repos every startup founder should bookmark. All open-source. All free.

1. /remotion (⭐️ 58K) 
Make demo videos in React or prompt: https://github.com/remotion-dev/remotion

2. /recordly (⭐️ 23K) 
Screen studio record and zoom: https://github.com/webadderallorg/recordly

3. /dify (⭐️ 154K) 
Build and run AI agents and workflows: https://github.com/langgenius/dify

4. /gstack by @garrytan (⭐️ 131K) 
Claude as your full dev team: https://github.com/garrytan/gstack

5. shadcn/ui (⭐️ 122K) 
Beautiful UI components, copy and paste: https://github.com/shadcn-ui/ui

6. /supabase (⭐️ 108K)

7. /marketingskills (⭐️ 44.8K)
CRO, copywriting, SEO, analytics automated: https://github.com/coreyhaines31/marketingskills

8. /postiz-app (⭐️ 35K)
