### install the skills

skills are instruction packs, and they're the part that stops Claude from guessing

the repos show Claude what good output looks like, while the skills hand it the working rules for each framework, so it builds the way the framework expects

paste these into your terminal, one at a time:

text

npx skills add remotion-dev/skills
claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes
claude plugin marketplace add buildwithhanif/claude-animation-skill
claude plugin install claude-animation@claude-animation-skill
