# مسودة تعديلات المواصفة والدستور (تتجمع لين جلسة المالك)

> **الهدف:** وقت تعديل الدستور والقرارات نرجع للمالك بقائمة جاهزة، كل بند بمثال. **ما ينطبق شي هنا قبل موافقته** وقبل ما نمشي Spec Kit (specify ← clarify ← plan …).
> **المصادر:** القرارات 41–59 (`خام/تشريح/_قرارات-مبدئية.md`)، ونتائج اختبار النماذج (لما يصير)، ودراسات الكود (`خام/موارد-خاصة/دراسات-الكود/`).

## أ) من القرارات 41–59 (لازم تدخل)
- مزايا الإصدار الأول ف1–ف8 (أحسن محاولة، دكتور الهوك، 3 نسخ، عدّاد المعرفة، حشو حسب اللهجة، احترام الآيات، المنطقة الآمنة، شارة الخصوصية) + ف14 الأرقام.
- السعر 59 ريال شهري، ميسر، بدون سنوي بالبداية، MCP الخيار 3 (القرارات 59 وجلسة الدفع).
- (القائمة الكاملة تنسحب من ملف القرارات وقت الجلسة.)
