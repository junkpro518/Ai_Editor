## ما هو
كان «KrillinAI» أداة توطين فيديو (تفريغ ← ترجمة ← دبلجة ← تصدير أفقي/عمودي). المستودع الآن أعاد التسمية إلى **OpenCreator**: مساحة عمل للمبدعين مبنية فوق Codex CLI كمحرّك وكيل، وفيها عشر أدوات (ترجمة فيديو، تنزيل، صور، فيديو، TTS، مقالات…). نواة الترجمة القديمة صارت `runtime/krillinai` (Go) وتُشغَّل عبر CLI تستدعيه Skills.

## الأفكار
- كل مرحلة (subtitle / tts / render-horizontal / render-vertical / cover) أمر CLI مستقل يطبع JSON ويكتب `krillinai_manifest.json` — مناسب جداً لوكيل.
- وضع `--dry-run` يتحقق من الخطة دون تحميل أو نداءات AI.
- حالة مشتركة واحدة بين الواجهة المرئية والمحادثة («Dual-mode»)، وكل تعديل ينشئ نسخة جديدة (Versioning) دون الكتابة فوق السابق.
- قوالب إنشاء (Creation Templates) تعرض النتيجة والبرومبت والإعدادات والمؤلف والمصدر، وزر «Use this template».
- ترجمة بسياق: ملخّص لكل فصل + قاموس مصطلحات بالدليل (IDs) لمنع «انجراف المفاهيم» بين الدفعات، ثم مراجعة كاملة للترجمة وتحقق مستقل من التغييرات.

## المميزات (فعلياً)
- ترجمة فيديو: 123 لغة مصدر / 124 هدف (والتغطية تعتمد على النموذج المختار).
- تفريغ: سحابي أو محلي — ملفات `pkg/` تُظهر fasterwhisper وwhispercpp وwhisperkit (Apple) وwhisperx وAliyun ASR وواجهة OpenAI-compatible.
- دبلجة: Edge TTS (محلي/مجاني)، OpenAI TTS، Aliyun TTS + استنساخ صوت، أو عينة صوت مخصصة.
- ترجمة ثنائية اللغة: مخرجات `origin_language_srt.srt`, `target_language_srt.srt`, `bilingual_srt.srt`, `short_origin_mixed_srt.srt`.
- محرر ترجمة غامر (موجة صوت + تايم لاين، تقسيم/دمج، بحث واستبدال) واستيراد SRT للترجمة فقط.
- تصدير أفقي وعمودي (أغلفة، عناوين، ترجمة ثنائية)، وتنزيل من YouTube/X/TikTok/Instagram… عبر yt-dlp.
- «Auto Clips» (اكتشاف اللقطات المميزة) و«Digital Avatar» ما زالا **قيد التطوير** وليسا متاحين.

## التقنيات والبنية
- الحزم/المكتبات: pnpm monorepo (`apps/daemon|desktop|web|harness`, `packages/protocol|skill-market|stickman-remotion`), Go runtime، yt-dlp، ffmpeg، Codex CLI.
- المعمارية: Web هو الواجهة الوحيدة وDesktop يحمّله ويضيف ميزات النظام. البيانات والسجلات محلية افتراضياً، مع موافقات وتشخيص منقّح. الوكيل = Codex (لا حلقة وكيل خاصة).
- **العربية/RTL:** نعم في الواجهة (43 لغة واجهة مع RTL للعربية والفارسية والأردية والعبرية، `apps/web/src/styles/rtl.css`) وفي التصيير: `subtitle_fonts.go` يختار خطوط احتياطية حسب النص (يتعرف على Arab/Hebr/Deva) وخطوط مدمجة لتحسين الكتابات المعقدة وRTL. العربية ليست مذكورة صراحة كلغة نص لكن لا شيء يمنعها.
- **خط الترجمة النصية:** SRT/VTT. دعم VTT بنمط الكلمة-بالكلمة (inline word timestamps) أو الكتل الكاملة. التصيير يستخدم ملف أنماط JSON (`subtitle-style-default.json`) بحقول مطابقة تماماً لـ ASS (`font_name, primary_color, outline, alignment, margin_v, encoding`) لكلا الاتجاهين `horizontal`/`vertical` ومستويين `major`/`minor` (لغة أساسية وثانوية). يوجد `subtitle_frozen_layout.go` و`subtitle_layout_review.go` (مراجعة تخطيط الأسطر بنموذج) و`scripts/verify-subtitle-render-parity.ts`.
- مثال أمر: `krillinai subtitle "<input>" --origin-lang en --target-lang zh_cn --workdir $WORKDIR --caption-source any --prepare-video`.
- محلي مقابل API: التفريغ والـTTS يمكن أن يكونا محليين؛ الترجمة تتطلب LLM (OpenAI-compatible، قد يكون محلياً)؛ بعض الخدمات سحابية مدفوعة.

## أشياء نأخذها لمشروعنا
- **عقد CLI/المانيفست**: أمر لكل مرحلة + JSON نهائي + manifest + dry-run. لماذا: يجعل المحرر قابلاً للأتمتة بالوكيل وMCP. يخدم: الوكيل/التشغيل.
- **ملف أنماط الترجمة JSON** بحقول ASS لكل اتجاه (أفقي/عمودي) ومستوى: بذرة ممتازة لقسم «النصوص والترجمة» في نمط المحرر. يخدم: نظام الأنماط.
- **ترجمة بسياق وقاموس مصطلحات بالدليل** ومراجعة بتحقق مستقل: مهم لقناة دينية/تعليمية حيث الدقة حرجة. يخدم: الوكيل/الترجمة.
- **خطوط احتياطية تلقائية حسب السكربت** للعربية. يخدم: التصدير.
- **نسخ مستقلة (Versioning) لكل تعديل** وحالة مشتركة بين المحادثة والواجهة: يطابق مبدأ «المستخدم يعدّل يدوياً أو بالمحادثة». يخدم: المحرر.
- **قوالب فيها برومبت+إعدادات+مؤلف+مصدر**: نموذج لبطاقة «حزمة نمط». يخدم: نظام الأنماط.
- أمر `Pipeline Plan` للتحقق من خطة متعددة المراحل قبل التنفيذ: يطابق «خطة ثم تنفيذ».
