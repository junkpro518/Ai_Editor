## ما هو
أداة لإزالة خلفية الصور تعمل كـ CLI أو مكتبة Python أو خادم HTTP أو Docker. التويت دقيق. اللافت: أمر `rembg b` يقبل تدفق RGB24 من ffmpeg، يعني **إزالة خلفية الفيديو إطاراً إطاراً**.

## الأفكار
- جلسات (sessions) = نماذج قابلة للتبديل: u2net / u2netp / silueta / isnet / birefnet (general, portrait, massive, HRSOD, lite) / bria-rmbg / SAM (بنقطة نقر) / dis_anime / cloth_seg / أو نموذج مخصص / أو API سحابي (withoutbg، Atlas Cloud).
- أوضاع الحواف: افتراضي، `-dc` إزالة تلوّث اللون، `-a` alpha matting، `-vm` ViTMatte.
- إعادة استخدام الجلسة (`new_session`) للدفعات.

## المميزات
- أوامر `i` لملف، `p` لمجلد (مع `-w` مراقبة)، `s` خادم + Gradio، `b` تدفق ffmpeg، `d` تنزيل النماذج.
- خادم HTTP: `POST /api/remove` وتوثيق على `/api`.
- GPU عبر CUDA أو ROCm أو CPU.

## التقنيات والبنية
- الحزم/المكتبات: onnxruntime (cpu/gpu/rocm)، PIL، numpy، OpenCV، pymatting.
- المعمارية: محلي بالكامل؛ ملفات `rembg/sessions/*.py`. النموذج الافتراضي bria-rmbg ~1.02GB بدقة 1024.
- أمثلة: `rembg i -m birefnet-portrait in.png out.png`, `ffmpeg -i in.mp4 -an -f rawvideo -pix_fmt rgb24 pipe:1 | rembg b 1280 720 -o out-%03u.png`.

## أشياء نأخذها لمشروعنا
- **تنظيف الأصول (ج):** إزالة خلفية الشعارات واللقطات الثابتة وصور الضيوف داخل المحرر، كأمر في الوكيل: «أزل خلفية الصورة وضعها على المسار 3». أين: المحرر/الوكيل.
- **خلفية الصورة الشخصية للأغلفة (أ):** قص المتحدث ثم وضعه فوق خلفية قالب الغلاف. أين: التوليد.
- نستخدم **BiRefNet (MIT)** أو u2net (Apache) كنموذج افتراضي للتوزيع التجاري بدل bria. (التحقق من ترخيص كل نموذج قبل الحزم.)
- الفيديو: `rembg b` يعمل لكنه إطاراً إطاراً بلا اتساق زمني (وميض في الحواف)؛ للفيديو الحقيقي نحتاج نموذج فيديو matting (مثل ما يظهر في Spaces: LTX Alpha Matte). أين: المحرر.
