## ما هو
موقع Skillry (متجر «Agent Skills») فيه قسم «AI videos» يجمع فيديوهات صنعها الناس بـ Claude Opus 5.5 مع **البرومبت الأصلي** و**إعادة بناء حية (Remake)** بجانبها. التغريدات تقول 389؛ الصفحة اليوم تقول **418** (229 موشن جرافيك، 68 شروحات، 56 مشاهد 3D، 65 ألعاب) — تزداد.

## الأفكار
- كل بطاقة = **الفكرة الأصلية + النتيجة + البرومبت** (كما في تغريدة Charlie Hills) مع زر «Play both» لعرض الأصل والـRemake جنباً إلى جنب.
- الاستعمال المقترح: خذ فيديواً يعجبك + شعارك وألوانك وخطوطك → أعطه لـ Claude ليُنتج نسخة بهويتك (أي «نمط مستعار + أصول العلامة»).
- كل بطاقة مرتبطة بـ **Skills مثبّتة** (مثل «Plush Crew Launch Video» و«Notion Style Localize Video») بعدد التثبيتات ليُنفَّذ المثل نفسه بالوكيل.

## المميزات (فعلياً)
- تصنيف بأربع فئات + وسوم تقنية على كل بطاقة (Three.js, GLSL, Canvas, SVG, GSAP, Web Audio, Remotion).
- **ملاحظة مهمة:** هذه ليست فيديوهات مولَّدة بنماذج فيديو؛ هي **كود** (HTML/Three.js/Remotion) يكتبه Claude ويُصيَّر إلى فيديو. مثال: «Build me a human heart in interactive 3D, in one HTML file with Three.js… No images. Do not ask me any questions. Just build it.»
- أمثلة برومبتات منظمة: وسم `<direction>` يتضمن مفهوماً في سطر، قيود انتقالات («No cuts, no fades»)، خط واحد (Geist بأوزان وأحجام)، لوحة ألوان بأكواد hex.
- شروحات سير عمل (ياباني): Claude يدخل الأداة، يكتب مواصفات، يلتقط لقطات، يكتب سيناريو، ينفّذ بـ Remotion، يولّد تعليقاً صوتياً بـ TTS، يقسّم الصوت لـ 32 عبارة ويزامن النص، ويؤلف الموسيقى بالكود مع خفض تلقائي تحت الصوت — 52 ثانية.

## التقنيات والبنية
- موقع Next-like: صفحات `/ai-videos/opus-5-5/<handle>-<id>`، بطاقة = {handle، فئة، المدة، نص البرومبت، وسوم تقنية، فيديو الأصل، فيديو الـRemake، رابط التغريدة الأصلية، Skills ذات صلة}.
- لا واجهة API معلنة؛ الاسترجاع بتصفح الصفحات.
- الجدير بالذكر: «البرومبت» وحده لا يكفي؛ الوكيل يحتاج Skill + أصول العلامة.

## أشياء نأخذها لمشروعنا
- **هيكل بطاقة النمط = مرجع بصري + برومبت/قواعد + وسوم تقنية + نسخة مُعاد بناؤها + Skills مرتبطة**: يصلح تماماً لواجهة «مكتبة الأنماط» عندنا. يخدم: نظام الأنماط.
- **عرض الأصل والنتيجة جنباً إلى جنب (Play both)** عند تحليل فيديو مرجعي واستخراج نمط: يبني ثقة المستخدم بالاستنتاج. يخدم: نظام الأنماط/المحرر.
- **«أعطِ النمط + أصول علامتي»**: عملية «ربط النمط بأصول العلامة» (شعار، ألوان، خط) كخطوة صريحة في إنشاء مشروع. يخدم: الأنماط.
- **نمط برومبت منظم** (مفهوم في سطر، قيود انتقال، خط، ألوان hex): قالب لحقول النمط النصية التي يتحول إليها وصف المستخدم. يخدم: الأنماط/الوكيل.
- **مسار «كود ← فيديو» (Remotion/HTML)** كمحرك رسوم متحركة قابل للتحرير (طبقة موشن) داخل التايم لاين. يخدم: التوليد/المحرر.
- مصدر ممتاز لتجميع **أمثلة اختبار** لنظام استنتاج الأنماط.

## استلهامات
- نجاح التغريدات (149K و131K مشاهدة، 3.2K إعجاب): «قائمة ضخمة + قابلة للنسخ + بجانب الأصل». الأرقام (389) والعبارة «انسخ كل برومبت» محرك رئيسي.
- صيغة الخطوات «→ الفكرة الأصلية → النتيجة → البرومبت» قصيرة وتُفهم في ثانيتين.
- تعليق مفيد في الردود: «عدّل البرومبت لسياقك، تعديل صغير يغيّر النتيجة» — الجمهور يريد تخصيصاً.
- الاعتماد على تسعير Skills ($9.99/شهر) مع مجانية البرومبتات.

## تحذيرات ومخاطر
- حقوق: البرومبتات والفيديوهات لأصحابها؛ لا نعيد نشرها، نكتفي بالنمط.
- الأرقام تتغير (389 ثم 418)؛ الموقع تجاري ومعتمد على Claude Opus.
- الموشن المكتوب بالكود لا يصلح لفيديو واقعي مصوّر؛ يخص الشروحات والموشن جرافيك.
- لا توجد مجموعة بيانات مفتوحة قابلة للتنزيل؛ مستودعات مجتمعية ثانوية مثل `HiAPIAI/awesome-opus-5-5-video-styles` (425 برومبت في 12 نمطاً بصرياً، 37 نجمة) قد تكون أيسر للتحليل لكن لم أفتحها.
