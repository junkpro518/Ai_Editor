## ما هو (3–6 أسطر)
تغريدة سعودية تشرح بناء "استوديو موشن" مرة واحدة ثم استعماله يومياً: افتح مجلداً في Claude Code، خلّه يبني مشروع Remotion، أعطه الهوية (ألوان، خط، نوع الحركة، 1080×1920)، خلّه يصنع Components ثابتة (عناوين، كروت، واجهات، كود، CTA)، وبعدها كل يوم أعطه الموضوع فقط فيقسّمه مشاهد ويُخرج الفيديو بنفس الستايل. البرومبت: "ابني لي Motion Graphics Studio باستخدام Remotion + React + TypeScript. Design System ثابت، Components قابلة لإعادة الاستخدام، Scene Engine، ودعم عربي RTL. 1080x1920 و30fps، الستايل Premium Tech Motion. بعدها أقول لك فقط: سو لي فيديو عن [الموضوع]".

## الأفكار (قائمة)
- "ابنِ الاستوديو مرة، استخدمه يومياً" بدل البدء من الصفر في كل فيديو.
- فصل ثلاث طبقات: **Design System** (هوية) / **Components** (عناصر ثابتة) / **Scene Engine** (يحوّل موضوعاً إلى مشاهد).
- المُدخل اليومي = موضوع فقط؛ الستايل محفوظ.
- قابلية ربط أي API لاحقاً: صوت، صور، فيديو، ترجمة، توليد سكربت ← سلسلة كاملة من الفكرة إلى الفيديو.

## أشياء نأخذها لمشروعنا (قائمة، كل بند: ماذا + لماذا + أين يخدم الرؤية)
- **تقسيم الطبقات الثلاث (Design System / Components / Scene Engine)** ← يطابق تقسيمنا: النمط (هوية + قواعد) / مكتبة أصول وقوالب نصوص وحركات / الوكيل الذي يطبّق. يخدم: نظام الأنماط + الوكيل.
- **"الموضوع فقط" كمُدخل** ← تجربة المستخدم المستهدفة بعد بناء النمط. يخدم: الوكيل/الشات.
- **دعم RTL كمتطلب أول** — ولتنفيذه نعتمد قواعد `remotion-markup/arabic-text.md`: `dir="rtl"` + `lang`، كشف الاتجاه بعدّ الكلمات، تحريك بالكلمة لا بالحرف، وعند الحاجة تقطيع الحروف بـZWJ مع إبقاء لام-ألف والتشكيل والأرقام/اللاتيني كوحدة، خطوط عربية صريحة (Noto Sans Arabic, IBM Plex Sans Arabic, Cairo, Tajawal)، تجنّب `letterSpacing`، وتحذير Safari (خطوط بلا U+200D). يخدم: النصوص والترجمة.
- **إعداد عمودي 1080×1920@30fps كقالب نمط افتراضي** لصنّاع المحتوى القصير. يخدم: النمط (المشهد والتكوين).
