**تحقق من المصدر الأصلي:** جزئي — صفحة النظرة العامة فقط (الوصف: بلا رسوم egress)؛ حاولت جلب صفحة الأسعار فلم تُستخرج الأرقام، فهي من معرفتي، راجعها

## ما هو
تخزين كائنات متوافق مع S3 بدون رسوم خروج بيانات. في مشروعنا: تخزين سحابي اختياري للمزامنة والنسخ الاحتياطي ومشاركة المعاينات، وليس مطلوباً للتجربة المحلية (كما في vision.md).

## الأفكار
- رفع مشاريع/وكلاء (proxies منخفضة الدقة) للمزامنة بين أجهزة المستخدم.
- روابط مشاركة معاينة مؤقتة (presigned URLs).
- تخزين النماذج والأنماط المشتركة (متجر أنماط لاحقاً).

## المميزات
- S3 API فتعمل أدوات AWS SDK / rclone.
- بدون egress، فتكلفة المشاهدة والتنزيل المتكرر منخفضة.
- يرتبط بـWorkers وCDN.
- تشفير في السكون.

## التقنيات والبنية
- الحزم/المكتبات: `@aws-sdk/client-s3`، أو R2 binding داخل Worker.
- المعمارية: التطبيق المحلي يطلب presigned URL من خادمنا الصغير ثم يرفع مباشرة؛ لا مفاتيح في التطبيق.

### التكلفة (تقريبية، للتحقق)
- تخزين: ~0.015 دولار/GB شهرياً، مع 10GB مجانية.
- عمليات: Class A (كتابة) ~4.5 دولار/مليون، Class B (قراءة) ~0.36 دولار/مليون، مع حصة مجانية.
- egress: صفر.
- مثال: 1TB فيديو = نحو 15 دولار شهرياً.
- بدائل: Backblaze B2 (أرخص تخزيناً)، AWS S3 (egress مكلف)، Supabase Storage (متاح لدينا ضمن أدوات)، Wasabi.

## أشياء نأخذها لمشروعنا
- تأجيله: لا نبني مزامنة قبل إثبات الطلب — يخدم تقليل الكلفة.
- عند الحاجة: طبقة تخزين مجردة بواجهة S3 لنبدّل المزود بسهولة — يخدم التشغيل.
- رفع الـproxies وليس الأصول الأصلية لتقليل التكلفة — يخدم الاقتصاديات.

## استلهامات
"لا رسوم egress" نقطة تسويقية تهم المنتجات التي تعرض فيديو.

## تحذيرات ومخاطر
- تعارض مع المعالجة المحلية والخصوصية إن رُفعت الملفات الخام؛ يجب موافقة صريحة.
- مسؤولية قانونية عن محتوى المستخدمين (DMCA، حقوق).
- ميزات S3 غير كاملة التوافق (بعض lifecycle/ACL).

## أسئلة مفتوحة
- هل نحتاج سحابة أصلاً في الإصدار الأول؟
- من يدفع التخزين: المستخدم (BYOK/حسابه) أم نحن ضمن الباقة؟
