## ما هو
قائمة سبعة أدوات لتشغيل AI على جهازك: Colibri، LocalAI، Whisper.cpp، AnythingLLM، Unsloth، ComfyUI، Ollama. المنشور دعائي (الكلمة المفتاحية «RIG» للحصول على رابط).

## الأفكار
- تشغيل محلي على أجهزة عادية بدل سيرفر ضخم.
- LocalAI كطبقة API موحدة (متوافقة مع OpenAI) فوق عدة محركات.

## المميزات (مما تحققت منه)
- **LocalAI** (v4.9 أغسطس 2026): LLM + رؤية + صوت + صور + فيديو خلف API واحد؛ دعم MiniMax-H3 فيديو مع صوت، وimage-to-3D (v4.8)، وwhisper.cpp للنسخ، وعملاء MCP وAgents؛ "لا يحتاج GPU".
- **whisper.cpp**: نسخ صوتي محلي بـ C++ (MIT).
- **ComfyUI**: واجهة عقد للصور/الفيديو (GPL-3.0).
- Colibri: غير مؤكد (نتائج البحث ضعيفة).

## التقنيات والبنية
- الحزم/المكتبات: llama.cpp، whisper.cpp، stable-diffusion.cpp، GGML.
- المعمارية: «نواة صغيرة + backends كصور Docker تُسحب عند الحاجة» (LocalAI)؛ محلي كلياً.

## أشياء نأخذها لمشروعنا
- **LocalAI كطبقة تجريد موحّدة (أ/ب/ج):** نفس API لنسخ الصوت، توليد صور، وفيديو محلياً، يخدم رؤية «محلي/هجين» ويقلل ارتباطنا بنموذج واحد. أين: التشغيل.
- **whisper.cpp** للتفريغ والتوقيت (مهم للترجمة والقص حسب الكلام). أين: المحرر/الوكيل.
- **ComfyUI كمنفّذ أعمدة التوليد:** FreeVideo يعمل داخله. لكن GPL-3.0 يمنع تضمينه؛ نستدعيه كعملية منفصلة عبر HTTP فقط.
