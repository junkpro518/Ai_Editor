## ما هو
نموذج TTS واستنساخ صوت بالقليل من العينات: Zero-shot من 5 ثوانٍ، وFew-shot بضبط دقيق على دقيقة واحدة. يأتي مع WebUI وأدوات تجهيز بيانات (فصل مرافقة صوتية UVR5، تقطيع تلقائي، ASR، وسم نصوص) وخادم API (`api_v2.py`).

## الأفكار
- مرجع صوت قصير + نصه (`ref_audio_path` + `prompt_text` + `prompt_lang`) يكفي للتوليد.
- ضبط دقيق خفيف لتحسين التشابه.
- استدلال عبر لغات (تدريب بلغة وتوليد بأخرى).

## المميزات (فعلياً)
- لغات النص المدعومة: **الإنجليزية واليابانية والكورية والكانتونية والصينية فقط**. لا عربية (الملفات في `GPT_SoVITS/text/`: chinese, japanese, korean, cantonese, english فقط، و`api_v2` يرفض أي `text_lang` غير مدعوم).
- سرعة: RTF 0.028 على 4060Ti، 0.526 على M4 CPU (v2 ProPlus).
- يعمل على CUDA وROCm وApple (تدريب Mac على CPU بسبب الجودة) وCPU.

## التقنيات والبنية
- PyTorch 2.5–2.7، Python 3.10–3.12، ffmpeg.
- محلي بالكامل؛ خادم HTTP: `GET/POST /tts?text=…&text_lang=zh&ref_audio_path=…&prompt_lang=…&text_split_method=cut5&streaming_mode=true&media_type=wav`.
- نسخ نماذج: v2، v2ProPlus، v3 (LoRA)، v4 (حسب README والـchangelog).
- مدمج كمحرك TTS ضمن VoiceStudio (`gpt-sovits`).

## أشياء نأخذها لمشروعنا
- **محرك اختياري لاستنساخ الصوت** في طبقة الدبلجة للغات CJK فقط. يخدم: التوليد.
- **واجهة HTTP محلية بسيطة** كنموذج لعزل محركات TTS خلف sidecar. يخدم: التشغيل.
- لا يصلح للعربية؛ لعربيتنا نبحث في محركات أخرى (انظر VoiceStudio: OmniVoice/CosyVoice…).
