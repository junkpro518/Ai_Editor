## ما هو (3–6 أسطر)
خط إنتاج «موضوع ← Short منشور»: بحث DuckDuckGo عن الحقائق ← سكربت 60–90ث بـ LLM ← 3 صور B-roll بـ Gemini Imagen مقصوصة 9:16 ← تعليق صوتي ← ترجمة Whisper كلمة بكلمة ← تجميع FFmpeg (Ken Burns + موسيقى + ducking) ← رفع ليوتيوب (خاص افتراضياً). الإضافة المميزة في v3: **«ملف النيش» (Niche Profile) بصيغة YAML** يوجّه كل مرحلة.

## الأفكار (قائمة)
- **ملف نيش واحد يشكّل كل المراحل** (النبرة، الخطافات، الصور، الصوت، الترجمة، الموسيقى، الصورة المصغرة) — 15 نيش جاهز + بناء نيشك في 5 دقائق.
- بوابة ضد الهلوسة: السكربت يستخدم فقط حقائق من البحث.
- مراحل قابلة للاستئناف (`state.py`)، وأوامر منفصلة `draft / produce / upload / topics`.

## المميزات (قائمة، ما يفعله فعلاً لا ما يدّعيه التويت)
- الترجمة: Whisper بطوابع كلمات ← مجموعات 4 كلمات ← ملف ASS بتمييز الكلمة النشطة (`\c` لون + `\b1` + `\fs80`) يُحرق، وSRT يُرفع ليوتيوب؛ لون التمييز والخط من ملف النيش (خطوط CJK مدعومة في v3.1).
- TTS: Edge TTS مجاني (افتراضي، مع تثبيت إصدار لأن 6.x يُرفض بـ 403)، ElevenLabs ‏~$0.05/فيديو، MiniMax، 60db (لغات هندية)، `say` في ماك.
- LLM: Claude (‏~$0.02/سكربت، افتراضي)، Gemini، GPT، Ollama، MiniMax، LiteLLM، Claude CLI.
- التكلفة المعلنة: ‏~$0.11 للفيديو (Claude + Gemini + ElevenLabs)، ‏~$0.04 بالمسار الاقتصادي.
- غير منفّذ رغم ذكره: Pexels، TikTok/Reels upload، واجهة Gradio، Docker (README يعترف بذلك صراحةً).

## التقنيات والبنية
- الحزم/المكتبات: Whisper، edge-tts، FFmpeg مع libass، Gemini Imagen، YouTube Data API (OAuth).
- المعمارية: ملف مسودة (draft JSON) لكل فيديو ينتقل بين المراحل؛ لا تايملاين ولا محرر. محلي + APIs.
- أمثلة ملموسة: `niches/tech.yaml` → `script{tone, pacing, hooks[{pattern, template}], cta_variants, word_count, forbidden[]}`, `visuals{style, mood, subjects, avoid}`, `voice{pace, energy, suggested_voices}`, `captions{highlight_color, font_weight, position}`, `music{mood, energy}`, `thumbnail{style, text_position}`. الأمر: `python -m verticals run --topic "…" --niche tech`.

## أشياء نأخذها لمشروعنا (قائمة، كل بند: ماذا + لماذا + أين يخدم الرؤية)
- **Niche Profile كنموذج مبسّط لـ«النمط»:** خاصة `forbidden[]` و`avoid[]` (ممنوعات) مقابل `hooks`/`style` (تفضيلات) — يطابق «القواعد الإلزامية مقابل التفضيلات» (§4.1). ← نظام الأنماط.
- **قوالب الخطافات بأنماط مسماة** (`contrarian_take`, `breaking_news`…) — حقل محتمل في النمط للمحتوى المولَّد. ← نظام الأنماط/التوليد.
- **ASS بتمييز الكلمة النشطة** — أبسط تنفيذ لترجمة «كلمة بكلمة» عبر FFmpeg/libass محلياً. ← المحرر/التصدير.
- **بوابة «الحقائق من البحث فقط»** — مبدأ مفيد للنمط الديني/التعليمي (لا إضافة معلومات من ذاكرة النموذج). ← الوكيل.
