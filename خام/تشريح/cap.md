## ما هو (3–6 أسطر)
بديل مفتوح لـ Loom: تسجيل شاشة وكاميرا وميكروفون على macOS وWindows، مع وضعين: Instant (يرفع أثناء التسجيل ويعطي رابط مشاركة) وStudio (تسجيل محلي ثم محرر فيه خلفيات وzoom وقص وترجمة وتصدير). التغريدة مجرد قائمة روابط (7 تطبيقات) بلا شرح، فكل التفاصيل من المستودع.

## الأفكار (قائمة)
- وضعان: «سريع للمشاركة» و«استوديو للصقل» — نفس مبدأ التحرير الخفيف بعد التسجيل.
- تحكم المستخدم بتخزينه: Cap Cloud أو S3 خاص (R2, B2, MinIO…) أو محلي أو استضافة ذاتية بـ Docker Compose.
- Cap AI: عناوين وملخصات وفصول وترجمة آلية.

## المميزات (قائمة)
- تسجيل شاشة/كاميرا/ميكروفون، محرر محلي (خلفيات، تكبير تلقائي، قص، ترجمة، تصدير)، روابط مشاركة وتعليقات وتحليلات، فرق ونطاق خاص، استيراد من Loom.
- لا يدعم Linux رسمياً (macOS وWindows فقط حسب README).

## التقنيات والبنية
- الحزم/المكتبات: Rust workspace؛ crates مهمة: `recording`، `rendering` و`rendering-skia`، `editor`، `export`، `enc-ffmpeg`، `enc-gif`، `cursor-capture`، `cursor-info`، `gpu-converters`، `video-decode`، `scap-screencapturekit`، `scap-direct3d`، `rnnoise`، `project`، `render-farm`.
- المعمارية: `apps/desktop` (Tauri) + `apps/web` + `apps/cli` + `apps/media-server` + `apps/mobile`. المشروع («project») كيان منفصل في crate `project` ثم `editor` و`rendering` يرسمان على GPU ثم `export` يرمّز عبر ffmpeg.
- أمثلة ملموسة: `docker compose up -d` للاستضافة الذاتية؛ في الجذر `AGENTS.md` و`CLAUDE.md` (المشروع نفسه يُطوَّر بوكلاء).

## أشياء نأخذها لمشروعنا (قائمة)
- **تقسيم crates بهذا الشكل** (capture / project / editor / rendering / export) مرجع جيد لحدود وحدات محرك الفيديو إذا اخترنا Rust/Tauri. يخدم: المحرر + التصدير + التشغيل.
- **زوم/حركة مؤشر تلقائية** من بيانات المؤشر (`cursor-capture`): فكرة «نمط» يطبقه الوكيل على تسجيلات الشاشة. يخدم: نظام الأنماط.
- **وضع Studio vs Instant** كنموذج للتصدير السريع مقابل المصقول. يخدم: التصدير.
- **تخزين متوافق مع S3/R2** للنسخة الهجينة (انظر cloudflare-r2.md).

## استلهامات
- شعار «own your data» وعرض كل خيارات التخزين في جدول واحد. تسعير: خدمة سحابية مدفوعة فوق كود مفتوح (Open Core مع AGPL) مع bounties على Algora.

- مستودع ضخم ومعقد (عشرات الـ crates)؛ ليس مرجعاً صغيراً للقراءة السريعة.
- لم أقرأ ملفات المصدر الداخلية، فقط البنية والـ README.
