## ما هو
بروتوكول مفتوح (من Anthropic) يربط عملاء ذكاء اصطناعي (Claude, ChatGPT, Cursor...) بخوادم تعرض أدوات وبيانات. عندنا: المحرر يصير خادم MCP يعرض أوامر المونتاج، فيقدر أي وكيل خارجي يقود المحرر.

## الأفكار
- ثلاثة primitives: **Tools** (إجراءات)، **Resources** (بيانات للقراءة، مثل حالة التايم لاين)، **Prompts** (قوالب).
- الوكيل الداخلي والخارجي يستدعيان نفس سجل الأوامر (موافق لنقطة الهندسة في vision.md).
- Transports: stdio (محلي) وStreamable HTTP (عن بعد).

## المميزات
- SDKs رسمية: TypeScript وPython وRust وغيرها.
- أدوات تحمل JSON Schema للمدخلات، فيتحقق العميل قبل الاستدعاء.
- تفويض OAuth للخوادم البعيدة، وإمكانية إرسال تقدم (progress) وإلغاء.
- دعم واسع لدى العملاء، ما يعني توزيعاً مجانياً (عملاء موجودون).

## التقنيات والبنية
- الحزم/المكتبات: `@modelcontextprotocol/sdk` (TS)، `mcp` (Python).
- المعمارية: داخل Electron، خادم stdio أو HTTP محلي على localhost يمرّر الأوامر لـcommand bus الذي يعدّل حالة التايم لاين (مع undo). المعاينة تُحدَّث تلقائياً.
- أمثلة ملموسة (أدوات مقترحة): `get_timeline`, `add_clip`, `split_clip`, `apply_style(style_id)`, `propose_style_update(diff)`, `export(preset)`.

## أشياء نأخذها لمشروعنا
- تصميم الأوامر كـcommand registry واحد بمدخلات JSON Schema، ثم نولّد منه أدوات MCP وأدوات الشات الداخلي — يخدم الوكيل.
- كشف حالة التايم لاين كـResource قابل للقراءة (لا يحتاج الوكيل لقراءة صور) — يخدم الوكيل.
- ربط الأنماط كـPrompts/Resources: `style://<id>` — يخدم نظام الأنماط.
- توزيع: "يعمل مع Claude Desktop وCursor" كميزة تسويق — يخدم النمو.

## استلهامات
المشاريع المذكورة في الوثيقة تذكر MCP وSkills كواجهة موازية للشات؛ الجمهور يحب فكرة "اطلب من Claude أن يقصّ".

## تحذيرات ومخاطر
- أمان: أدوات تحذف/تكتب ملفات؛ تحتاج صلاحيات وتأكيد وسجل (prompt injection من محتوى الفيديو/الترجمة).
- المخطط يتغير بتواريخ (إصدار مخطط جديد)؛ ثبّت نسخة واختبر التوافق.
- كثرة الأدوات تستهلك سياق النموذج؛ اجعلها قليلة وعالية المستوى.
- اشتراك المستخدم الشخصي لا يعني رصيد API (كما في vision.md)، لكن MCP عبر عميل مدعوم مسموح.

## أسئلة مفتوحة
- stdio أم HTTP محلي؟ وكيف نصادق العميل؟
- هل نكشف عمليات منخفضة المستوى أم أوامر "نمطية" عالية المستوى؟
