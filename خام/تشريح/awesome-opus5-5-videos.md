## ما هو (3–6 أسطر)
مستودع يجمع فيديوهات «فيروسية» صنعها الناس بطلب من Claude Opus 5.5 أن يكتب الأنيميشن **ككود** (HTML/Canvas/SVG/Three.js/shaders) ثم يُعرض في المتصفح، لا توليد فيديو مباشر مثل Veo. كل مدخل: البرومبت الأصلي + رابط منشور صاحبه. المنشور يقول 475 فيديو؛ الواقع الحالي في الملف 703 برومبت، منها 418 لها «ريميك» حي على موقع Skillry، ونحو 207 برومبتات جزئية (`prompt_partial`).

## الأفكار (قائمة)
- «الفيديو = كود يُرندر»: يمكن تسجيل صفحة HTML كفيديو، فالنموذج لا يحتاج نموذج فيديو.
- البرومبت كأصل قابل للتعديل: خذ الفكرة وبدّلها على مشروعك.
- عرض الأصل بجانب إعادة الإنشاء الحية يثبت أن البرومبت يعمل.

## المميزات (قائمة)
- تنظيم البيانات (`data/videos.json`): الحقول `slug, author, author_url, post_url, category, tech_tags, prompt, prompt_partial, poster_url, skillry_url, added, has_remake`.
- التصنيفات الأربعة: motion = 369، 3d = 117، explainer = 116، interactive = 101 (في README مجمّعة: Motion graphics وExplainers وGames & interactive و3D scenes).
- أشهر الوسوم التقنية: canvas 267، svg 183، threejs 131، shader 92، gsap 86، css 57، audio 39، playable 22، particles 17.
- مجلد `prompts/` ملف Markdown لكل فيديو: عنوان، رابط المنشور، `Category`، `Remake built with`، `Author`، ثم كتلة `## Prompt`.

## التقنيات والبنية
- الحزم/المكتبات: لا شيء؛ بيانات فقط. التنفيذ بالـHTML المفرد.
- المعمارية: README كجداول صور → ملف برومبت لكل عنصر → JSON موحَّد للبحث. «طريقة الاستخدام»: انسخ البرومبت، الصقه في Opus 5.5، اطلب ملف HTML واحد، سجّل الصفحة إن أردت فيديو.
- أمثلة: برومبت `twoclipping-402193` يستخدم وسوماً مثل `<inputs>` (يسأل المستخدم عن 8–12 حالة UI، لوناً، وأغنية 120 BPM) و`<direction>` (شكل واحد لا ينقطع يتحول بين الحالات، Springs، كاميرا تقرّب). ومثال بسيط: «لعبة 3D متعددة اللاعبين… x-wings ضد star destroyer».

## أشياء نأخذها لمشروعنا (قائمة)
- **هيكل البرومبت ذي القسمين `<inputs>` (ما يسأله الوكيل للمستخدم) و`<direction>` (الأسلوب)** نموذج جاهز لتعريف «نمط» بصياغة قابلة للتعبئة. يخدم: نظام الأنماط + الوكيل.
- **مكتبة برومبتات مُصنَّفة بوسوم** (category + tech_tags) كأساس لمعرض قوالب Motion Graphics داخل المحرر. يخدم: التوليد.
- **توليد طبقات Motion/Overlay كـHTML ثم رندر** (مثل hyperframes.md وremotion.md) لإدراجها على التايم لاين. يخدم: التوليد + التصدير.
- حقل `prompt_partial` فكرة جيدة: وسم «غير مكتمل» لقوالبنا.
