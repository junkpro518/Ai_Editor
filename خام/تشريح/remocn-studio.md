## ما هو (3–6 أسطر)
تطبيق سطح مكتب مجاني يجعل وكيل البرمجة الذي يملكه المستخدم (Claude Code، Codex، Copilot CLI، Grok Build) يصنع فيديو موشن جرافيك كـ **مشروع Remotion حقيقي** في مجلد على القرص. المستخدم يشاهد معاينة حية ويعطي ملاحظات بالكتابة أو بالنقر على عنصر أو بتحديد مربع لقطة. صراحةً: "لا تايم لاين، لا كي فريمز، لا إدارة مسارات". موجه لفيديوهات الإطلاق والترويج، لا لمونتاج لقطات خام.

## الأفكار
- **"لست مولّد بكسلات ولا قوالب"**: الطريق الثالث = الوكيل يكتب الموشن ككود قابل للتعديل.
- **ثلاث طرق لقول "هنا"**: اكتبها، أشر إليها (نقر يفتح لوحة خصائص وتعديلها يُكتب في الكود)، أو أطّرها (Snapshot كصورة في الشات).
- **خط إنتاج من 7 مراحل** كل مرحلة تترك وثيقة قابلة للتعديل: `analysis.md → brand.md → script.md → motion.md → build → choreography.md → review.md`.
- **استخدام اشتراك المستخدم الموجود**: يقود CLI الوكيل المسجّل دخوله بدل مفاتيح API — لا فاتورة توكنات منفصلة.
- مهارات موشن مدمجة + "سجل ما فشل على الشاشة سابقاً" (`video-lessons`) + أداة `design_check` تقيس الإطارات المرندرة (قابلية القراءة، التوقيت).

## المميزات
- معاينة حية لـ Remotion، تعديل نصوص بالنقر المزدوج، سحب/تحجيم، منحنيات easing.
- مكتبة مكونات remocn مدمجة مع "أدوار حركة" (entry/emphasis/exit/scene/transition) يختار الوكيل منها.
- براند المشروع عبر `DESIGN.md` أو اسم وألوان؛ Moodboard من صور مخزون عند غياب البراند.
- تصدير MP4/WebM/GIF/ProRes حتى 4K بأحجام المنصات.
- ElevenLabs اختياري للمؤثرات والموسيقى، وكل طلب مدفوع ينتظر موافقة.
- صلاحيات: تعديل ملفات المشروع بلا مقاطعة؛ أي أمر shell أو مسار خارجي = بطاقة إذن. أوضاع auto/accept edits/plan. لا يكتب في `~/.claude` وغيرها.
- عدة فيديوهات بالتوازي (حسب التويت والـ README).

## التقنيات والبنية
- الحزم/المكتبات: `@anthropic-ai/claude-agent-sdk`, `@openai/codex-sdk`, `@modelcontextprotocol/sdk`, `@remotion/player`, `@remotion/webcodecs`, Tauri 2 plugins، `effect`، `zod`.
- المعمارية: واجهة Next.js داخل Tauri ← sidecar (Bun) فيه محولات لكل وكيل (`sidecar/claude`, `codex`, `copilot`, `grok`, `acp` لبروتوكول Agent Client Protocol) مع permission/guard/session ← المشروع مجلد Remotion عادي:
  `.remocn/project.json` (هوية وبراند)، `src/videos/registry.tsx`، `src/videos/<video>/index.tsx` + `docs/`.
- أمثلة ملموسة: `sidecar/tools/tunability.ts` (ربط خصائص قابلة للضبط بالكود)، `sidecar/tools/review.ts`، مهارات `agent/skills/{motion-design, remocn, remotion-best-practices, remotion-interactivity, video-lessons}`.

## أشياء نأخذها لمشروعنا
- **الإشارة للعنصر من المعاينة وإرساله للشات كـ `[Element #1]`** — أفضل تجربة "عدّل هنا" رأيناها — المحرر/الوكيل.
- **Snapshot من الإطار كصورة للمحادثة** — للملاحظات البصرية — الوكيل.
- **مراحل موثقة كملفات قابلة للمراجعة** (تحليل، براند، سكربت، حركة، مراجعة) — تطابق "وضع خطة للمراجعة ثم التنفيذ" — الوكيل.
- **ملف براند/DESIGN.md يطبَّق على كل فيديو جديد** — جزء من النمط — نظام الأنماط.
- **أدوار الحركة (entry/emphasis/exit)** كوسوم على مكتبة الحركات ليختار الوكيل — نظام الأنماط/التوليد.
- **سجل الدروس/الأعطال المرئية** كمهارة يقرؤها الوكيل قبل البناء — الوكيل/الجودة.
- **قيادة CLI الوكيل باشتراك المستخدم** كخيار ثالث بجانب BYOK والرصيد — التشغيل/التكلفة (مع مراجعة شروط المزودين كما في الرؤية §8).
- **نموذج الصلاحيات** (داخل المشروع حر، خارجه بطاقة إذن) — الأمان.

## استلهامات
- جدول المقارنة "مولدات بكسل / محررات قوالب / نحن" واضح وقوي تسويقياً.
- لغة "أنت المخرج، هو يصوّر" و"ملاحظات على اللقطة" بدل لغة تقنية.
- "مشروعك مجلد على قرصك، لا ملف تستأجره" — رسالة ملكية تجذب صناع المحتوى.
- التويت العربي ركز على: مجاني، مفتوح، يعمل مع وكيلك، عدة فيديوهات، هويتك.

## تحذيرات ومخاطر
- Remotion نفسه برخصة تجارية (مجاني للأفراد والشركات الصغيرة، مدفوع للشركات الأكبر) — أي مشروع مولّد يرث هذا.
- ليس محرراً لمواد خام ولا تايم لاين — مكمل لا بديل.
- قيادة CLI الوكلاء باشتراك المستخدم قد تتعارض مع شروط بعض المزودين لاحقاً.
- 204 نجمة فقط، مشروع حديث.

## أسئلة مفتوحة
