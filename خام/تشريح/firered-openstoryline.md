**تحقق من المصدر الأصلي:** جزئي — README + `.storyline/skills/*/SKILL.md` + `skills_io.py` + `plan_timeline.py` + `render_video.py` + شجرة `src/`. المطابقة مع التويت غير مؤكدة: التويت يقول "14K+ نجمة" والمستودع 3.5K؛ بحثت أيضاً في FunClip (6.4K) وNarratoAI (11.5K) وViMax (12.7K) ولم يطابق أيٌّ منها الوصف (تقسيم مشاهد + إعادة ترتيب + ترجمات + MCP مع Claude Code/Codex/Cursor) مثل OpenStoryline.

## ما هو (3–6 أسطر)
وكيل مونتاج من فريق FireRed (Xiaohongshu) يحوّل المونتاج إلى "إخراج بالنية" عبر المحادثة. يقسم المقاطع للقطات، يفهم محتواها، يجمعها، يكتب سكربت وتعليقاً صوتياً، يختار موسيقى ويضبط القطع على الإيقاع، يخطط تايم لاين متعدد المسارات ثم يرندر. الأهم لنا: ميزة **"أرشفة مهارة المونتاج"** — حفظ أسلوب المونتاج الكامل كـ Skill (ملف SKILL.md) وإعادة تطبيقه على مواد جديدة.

## الأفكار
- **النمط = ملف Skill نصي**: ميتا-مهارة `create_profile_style_skill` تحلل التايم لاين الحالي أو تسأل المستخدم، تستخرج أبعاد الأسلوب (الإيقاع، السرد، الصوت والصورة، تفضيلات خاصة مثل "احذف الصمت دائماً" أو "B-Roll كل 5 ثوانٍ")، تعرض 3–5 نقاط للتأكيد، تقترح اسماً، ثم تكتب `cutskill_<name>/SKILL.md` بعد الموافقة.
- **نقل أسلوب الكتابة بالأمثلة (few-shot)**: `subtitle_imitation_skill` تأخذ نصاً مرجعياً وتقلد إيقاعه وبلاغته على محتوى الفيديو الفعلي.
- خط أنابيب عقدي (nodes) قابل للتتبع: كل عقدة تحفظ نتيجتها، والمهارات تقرأ تاريخ العقد (`read_node_history`).
- Human-in-the-loop: تعديلات بالمحادثة (قص، استبدال، إعادة ترتيب، لون/خط/موضع).

## المميزات
- عقد فعلية في `nodes/core_nodes/`: `load_media, split_shots, understand_clips, filter_clips, group_clips, asr_node, speech_rough_cut, generate_script, script_template_rec, generate_voiceover, select_bgm, recommend_effects, plan_timeline, plan_timeline_pro, generate_ai_transition, render_video, search_media`.
- مهارات جاهزة في `.storyline/skills/`: `default_editing_workflow_skill, speech_rough_cut_skill (حذف الحشو والتكرار بالـ ASR), subtitle_imitation_skill, ai_transition_editing_skill, create_profile_style_skill`.
- خادم MCP: `PYTHONPATH=src python -m open_storyline.mcp.server` مع hooks وsampling.
- مهارتا Claude Code/OpenClaw: `openstoryline-install` و `openstoryline-use`.
- قطع على الإيقاع (`BeatTrack`)، توصية خطوط وأصوات بحسب "النبرة".
- انتقالات AI مولدة (خدمة AIGC خارجية مكلفة — تنبيه في README).

## التقنيات والبنية
- الحزم/المكتبات: LangChain (`create_agent`, `ChatOpenAI`)، `skillkit` لاكتشاف المهارات وتحويلها لأدوات، moviepy للرندر، FFmpeg، FastAPI (`agent_fastapi.py`) وواجهة `web/`.
- المعمارية: `TimelinePlanner.plan()` يخرج `{"tracks": {video, subtitles, voiceover, bgm}}`، كل segment له `timeline_window {start,end}` بالميلي ثانية و`source_window`. الرندر عبر moviepy إلى MP4. لا تصدير لمحرر خارجي. LLM عبر API متوافق مع OpenAI (سحابي).
- أمثلة ملموسة: `dump_skills(skill_name, skill_dir, skill_content)` مع حماية Path Traversal؛ قالب المهارة المولّدة: "1. المبدأ العام 2. معالجة الصوت 3. العناصر المرئية 4. التحكم بالإيقاع 5. أدوات وبارامترات موصى بها".

## أشياء نأخذها لمشروعنا
- **دورة "استخلص النمط ← اعرض ملخصاً ← وافق ← احفظ كملف قابل للقراءة"** — تكاد تكون نفس حلقة "الوكيل يقترح تحديث النمط بعد موافقة" في الرؤية — نظام الأنماط.
- **أبعاد النمط الخمسة** (إيقاع، سرد، صوت، عناصر مرئية، أدوات وبارامترات) كبداية لمخطط حقول Style — نظام الأنماط.
- **النمط كمزيج: نص تعليمات + بارامترات أدوات** — يوضح أن Style Pack يحتاج جزءاً منظماً (JSON) وجزءاً نصياً للوكيل — نظام الأنماط.
- **نقل الأسلوب الكتابي few-shot** للتعليق والعناوين — التوليد.
- **عقدة speech_rough_cut** (حذف الحشو والتكرار مع محاذاة زمنية) — المحرر/القص.
- **فصل خطوات الخط في عقد بتاريخ** يسمح للوكيل بإعادة تشغيل جزء فقط — الوكيل.

## استلهامات
- ديمو بأسماء أنماط مفهومة للجمهور ("Zhongcao"، فكاهي، سفر، حصاد السنة) بدل أسماء تقنية.
- الصراحة: صف أول بأصول مفتوحة محدودة مقابل صف ثانٍ بأصول تجارية — يوضح أن الجودة تعتمد على مكتبة الأصول.
- التويت سوّق بـ"مطور صيني فتح المصدر" + رقم نجوم (مبالغ فيه على الأرجح).

## تحذيرات ومخاطر
- المطابقة مع التويت ليست مؤكدة، ورقم 14K غير مطابق.
- لا تايم لاين تفاعلي حقيقي للمستخدم: النتيجة MP4 من moviepy؛ التعديل بالمحادثة فقط.
- آخر دفع يوليو 2026 — قد يكون الزخم تباطأ.
- يعتمد على LLM سحابي وخدمات بحث/توليد خارجية؛ الانتقالات AI مكلفة.
- "النمط" نص حر يفسره LLM — لا ضمان للتطابق أو قابلية القياس.

## أسئلة مفتوحة
- ما جودة "نمط" مستخلص من تايم لاين واحد؟ هل يعمم على مواد مختلفة؟
- كيف نختبر أن تطبيق نمط محفوظ أنتج نفس الإحساس (مقياس تشابه)؟
- هل نقبل صيغة SKILL.md كتخزين للنمط أم نحتاج مخطط منظم مع إصدارات وفروقات؟
