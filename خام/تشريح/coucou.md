## ما هو
رفيق صغير يعيش في "نوتش" ماك بوك (أو أعلى الشاشة في Windows) يراقب جلسات Claude Code: يعرض ما تقرؤه وتعدّله الوكلاء، ويسمح بالموافقة/الرفض على الصلاحيات بنقرة، ويفتح الطرفية الصحيحة، ودردشة مدمجة. الشخصية Mochi مرسومة بالكود.

## الأفكار
- "حضور محيطي" للوكيل: واجهة دائمة صغيرة تظهر فقط عند الحاجة وتختفي عند الخمول.
- الشخصية تعطي الحالة: قفزة فرح عند النهاية، انزعاج عند النقر، دوار عند ثلاث نقرات.
- الموافقة على الصلاحيات من أي مكان بلا فتح الطرفية.

## المميزات
- جلسات Claude Code حيّة عبر hooks؛ Allow / Deny.
- سحب ملف على النوتش (تتحول إلى صندوق وتبتلعه) ثم سؤال عنه أو إرساله بريداً.
- سحب Mochi إلى أي نافذة لإرفاقها كسياق (macOS).
- تكاملات: Stripe, n8n, GitHub, Vercel, Resend, Notion, Cal.com (كل واحدة Mochi بلون).
- خصوصية: بلا telemetry، المفاتيح في Keychain / Credential Manager.
- Hook آمن: إن لم يعمل التطبيق يخرج فوراً ولا يحجب Claude Code.

## التقنيات والبنية
- الحزم: macOS بلا اعتماديات خارجية؛ Windows: Tauri 2.
- المعمارية: `NSPanel` بلا حدود تحت state machine (`hidden → petit → home`)؛ الشخصية في SwiftUI `Canvas` + `TimelineView` بـ 60fps: جسم squircle، عينان مسقطتان على كرة تتبعان الفأرة، وأنيميشن "spring" — **بلا Rive ولا Lottie ولا صور**. Windows: نفس الأشكال والتوقيتات في Canvas 2D.
- Claude Code: سكربت صغير `nb-hook` يمرّر أحداث الـ hooks عبر Unix socket إلى التطبيق؛ ولطلبات الإذن ينتظر النقرة ثم يردّ على الـ hook. على Windows: `coucou-hook.exe` + named pipe.
- التثبيت: يعدّل `~/.claude/settings.json` بعد نسخ احتياطي وعرض diff.
- 28 ملف WAV قصير بـ `AVAudioPlayer` محمّلة مسبقاً.

## أشياء نأخذها لمشروعنا
- **تكامل Claude Code hooks → التطبيق عبر socket محلي** (نمط `nb-hook`): قناة جاهزة لإشعارات "الوكيل ينتظر موافقتك على نمط/قصة" خارج نافذة المحرر. يخدم: الوكيل + التشغيل.
- **Approve/Deny بنقرة** كواجهة للوكيل حين يقترح "تحديث نمط" من تصحيحات المستخدم: بطاقة موافقة صغيرة. يخدم: نظام الأنماط.
- **شخصية مرسومة بالكود (Canvas + spring) بلا أصول**: مرجع مباشر لمفردات الحركة (تنفّس، رمش، عيون على كرة، squish) وتناسب ما وجدناه في anime.js (spring/ease). يمكن بناء "مؤشر وكيل" متحرك في المحرر بتكلفة نصف كيلوبايت.
- **اختفاء عند الخمول/ظهور عند الحاجة**: مبدأ مناسب لوكيل يعمل بالخلفية أثناء رندر طويل.
- **تثبيت hooks مع نسخة احتياطية وعرض diff** قبل تعديل ملفات المستخدم: ممارسة ثقة تُتّبع في MCP/الإعدادات.
