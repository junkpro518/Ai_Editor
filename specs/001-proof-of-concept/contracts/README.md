# العقود — الميزة 001

| الملف | ماذا يحدد | من يستهلكه |
|---|---|---|
| `project.schema.json` | مستند المشروع (مصدر الحقيقة): المصدر، التايم لاين، التفريغ، الكابشن، المقترحات، التصحيحات، اقتراحات تحديث النمط | الحفظ/التحميل، التحقق بعد كل أمر، لقطات التراجع |
| `style.schema.json` | إصدار النمط: أقسام ثابتة (`cut`, `captions`) كل حقل «قاعدة» بقيمة ووضع (إلزامي/تفضيل) ومصدر؛ سوابق (قاعدة + اقتباس + فحص)؛ `styleGuide` | مكتبة الأنماط، مولّد المقترح، مشتق الكابشن، اقتراح تحديث النمط |
| `transcript.schema.json` | عقد موحد لكل مزودي التفريغ (سحابي اليوم، محلي لاحقاً): كلمات بميكروثانية وثقة | محوّلات المزودين، مولّد المقترح، الكابشن، المراجعة |
| `commands.schema.json` | سجل الأوامر الموحد: 21 أمراً للميزة 001 مع معاملاتها وهل تؤخذ لقطة قبلها وهل تحتاج تأكيداً | طبقة التنفيذ الواحدة التي تخدم الواجهة اليوم وCLI/MCP لاحقاً (الدستور VII) |

## قواعد ثابتة

- **الزمن ميكروثانية صحيحة** في كل مكان؛ معدل الإطارات كسر `{num, den}`. التحويل لإطار: `floor(us * num / (den * 1e6))`.
- **كل أمر يمر بالمسار نفسه:** تحقق من المعاملات (schema) ← لقطة إن كان `undoable` ← تنفيذ نقي `(project, params) → project'` ← تحقق من `project.schema.json` والقيود البنيوية ← حفظ ذري ← إشعار الواجهة.
- **لا منطق مونتاج خارج الأوامر.** الواجهة تستدعي أوامر فقط.
- **الفاعل** (`user` | `agent`) يُسجَّل في كل مدخل تاريخ (FR-015).
- الأوامر الموسومة `confirm: true` تعرض نافذة تأكيد مستقلة قبل التنفيذ (الدستور III).

## الإصدار

`schemaVersion` في كل ملف؛ أي تغيير كاسر = رقم جديد + مُرحِّل. الميزة 001 تبدأ بـ 1.
