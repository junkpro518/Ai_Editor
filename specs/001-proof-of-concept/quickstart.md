# دليل التحقق السريع — الميزة 001

يثبت أن المسار يعمل من البداية للنهاية على جهاز القبول (macOS الآن، Windows لاحقاً). التفاصيل في [data-model.md](data-model.md) و[contracts/](contracts/README.md) و[research.md](research.md).

## المتطلبات

- macOS 13+ (Apple Silicon أو Intel) أو Windows 10/11 x64؛ Node 22 للتطوير؛ `pnpm`.
- عينات اختبار في `tests/fixtures/`: `talk-ar-10min.mp4` (حديث للكاميرا، خليجي + إنجليزي مخلوط، 1080p30)، `talk-ar-2min-mixed.mp4`، `music-only.mp4`، `long-16min.mp4`، `phone-vfr-hevc.mov`، `phone-4k.mp4`. الملفات الكبيرة خارج git (`scripts/fixtures/fetch.sh`)؛ المصدر والترخيص لكل ملف في `tests/fixtures/README.md` (T095، القرار 25).
- مفتاح Deepgram (أو ElevenLabs) للاختبارات السحابية يُدخل من شاشة الإعدادات؛ اختبارات CI تعمل باستجابات مسجّلة بلا مفاتيح.

## الإعداد

```sh
pnpm install
pnpm ffmpeg:fetch        # يتحقق من بصمة SHA-256 لثنائيات LGPL في resources/ffmpeg/<platform>
pnpm test                # vitest: وحدات + عقود (يجب أن تنجح قبل أي تشغيل)
pnpm dev                 # يشغّل التطبيق
```
